tailmon is installed

Open Terminal and try:

tailmon           # one snapshot of every machine
tailmon -w 1      # live view, refreshed every second
man tailmon       # the manual

If macOS asked to install the Command Line Tools, let it finish first: they provide Python 3.

To watch this Mac's files from other machines, or to use search, grep and mount on it, turn on Remote Login in System Settings → General → Sharing.

To uninstall:

sudo /usr/local/share/tailmon/uninstall.sh
